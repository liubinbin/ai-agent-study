# agent 思考

最近在思考 agent 架构，发现参考资料[1]总结得不错。它对单 agent、 agent skill、multi agent、agent teams 的梳理清晰，还补充写了一些历史，读起来顺畅，而且很容易理解。

初步判断：Single Agent 适合起步阶段或处理简单任务；Agent Skill 更擅长辅助分析或生成报告；Agent Teams 则可用于投决场景，由不同角色的 Agent 从多角度提供建议。Multi-Agent 架构暂时不在考虑范围内。
